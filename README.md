# EZ-Accounting Backend

This is the backend server for the EZ-Accounting budgeting app. It uses Express.js and MongoDB to store and manage budget data.

## Technologies Used

- Node.js
- Express.js
- MongoDB
- Mongoose
- Nodemon

## Features

- Connects to a local MongoDB database
- Uses Express.js to run a backend server
- Stores app data in the `eza_db` database
- Ready for budget, bill, salary, and expense routes
